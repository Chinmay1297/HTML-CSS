The Cascade

In the event of a conflict, which rule "wins"?

  1. Importance
  2. Origin
  3. Specificity
  4. Position

Importance

We can mark a declaration as important using the !important flag. This is always gonna win as its moved/elevated to the top of cascade.

If theres a tie between two declaration with importance, it would move to check Origin.

Origin

It looks at where the rule was defined.

There are 3 places where a rule can be defined:

  1. website- This is where you have control as a developer
  2. user
  3. browser - Each browser has its own set of styles.

Website styles overrides browser styles.

* has no specificity and selects everything. If you use * and change font weight to normal, then print a h1 tag, your style will win, even though h1 has a bold(provided by browser) weight. This is because Specificity comes after Origin.

Position

If importance is a tie, origin is a tie and specificity is a tie, then it goes down to the order of the rules defined (the latest added rule wins)
