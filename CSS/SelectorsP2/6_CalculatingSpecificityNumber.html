Calculating Specificity Number

The weight is determined by the number of selectors of each weight category in the selector matching the element (or pseudo-element).

Selector Id Class
Attribute
Pseudo-Class		 Type
Pseudo-Elements
#special 1 special: ID 0 0
.main a: hover 0 2 main: class, hover: pseudo class 1 a: element/type
1st one wins (it compares digits 1 by 1 from left to right (ID, Class, Pseudo)), which ever side wins first is applied
